# ArtiZynt — лендинг №2 (advertorial) под Испанию (ES)

Адаптация второго итальянского лендинга (Elementor-выгрузка) под Испанию.
Итальянского языка и упоминаний Италии в отдаваемых браузеру файлах не осталось.

---

## ⚠️ ЧТО НУЖНО ПРОВЕРИТЬ ПЕРЕД ЗАЛИВОМ

### 1. ID оффера в партнёрке
Не трогал — значения из итальянской связки. Под Испанию у партнёрки
почти наверняка **другой оффер**:

| Где | Параметр | Текущее значение |
|---|---|---|
| `send.php` | `$PRODUCT_ID` | `16389` |
| `send.php` | `$REF` | `1028188` |
| `send.php` | `$AD_API_KEY` | `c2ebbd20…` |
| `index.html` | `<input name="offer">` | `1243597` |
| `index.html` | `<input name="aff">` | `everad` |

Если не поменять — лиды из Испании уйдут не туда.

### 2. jQuery грузится с внешнего CDN
В `index.html`: `https://code.jquery.com/jquery-3.7.1.min.js`.
Так было в исходнике, я не менял. Если CDN недоступен, не заработают
телефонный инпут и плавная прокрутка по кнопкам. Если хочешь убрать
зависимость — положи jQuery локально (копия 3.6.0 лежит в
`ty/default-js/jquery.min.js`) и поменяй `src`.

### 3. Страница «спасибо» — её не было в архиве
`send.php` после отправки формы редиректит на `ty/index.php`, но папки `ty/`
во втором архиве **не было вообще** — то есть после отправки заказа юзер
получал 404.

Я положил туда испанскую `ty/` из первого лендинга (тот же оффер ArtiZynt,
тот же `send.php`, тот же редирект). Проверено: форма → 303 →
`ty/index.php?…&country=ES` → испанская страница благодарности.
Если у тебя есть своя `ty/` под этот лендинг — замени.

## ЧТО ИЗМЕНЕНО

### `index.html`
- `lang="it-IT"` → `lang="es-ES"`
- **Весь текст переведён на испанский:** шапка, хедлайны, буллиты, блок цены,
  зоны боли (CUELLO / ESPALDA / RODILLAS / DEDOS Y MANOS), описание продукта,
  «почему лучше других», два терапевтических эффекта, блок гарантии,
  форма заказа, все кнопки, FAQ целиком, алерты об ошибках
- Скрытое поле `country`: `IT` → **`ES`**
- Телефонный инпут: `title="Italia: +39"` → **`title="España: +34"`**,
  код `+39` → **`+34`**, плейсхолдер `320 123 4567` → **`612 345 678`**
- Флаг в разметке был `iti__ro` (**румынский** — остался от прошлой адаптации,
  при этом подпись была «Italia») → **`iti__es`**
- «Terapia completa #1 più venduta in **Italia**» → «…más vendida en **España**»
- «consegnare il prodotto in tutte le zone **d'Italia**» → «entregar el producto
  en toda **España**»
- Якорь `#ordina` → **`#pedido`** (9 ссылок + сам якорь) — он виден
  в адресной строке, когда юзер жмёт кнопку заказа
- Служебные подписи Elementor в `data-settings`:
  `Successivo`/`Precedente` → `Siguiente`/`Anterior`
- `alt` и `title` у картинок были техническим мусором (`2.png`,
  `mal-schiena.jpg`, `deliv-icon-copia-3-1-1-1.png`) — заменены на
  осмысленные испанские подписи
- Картинка `mal-schiena.jpg` (итальянское имя файла, видно в исходнике
  страницы) переименована в **`dolor-espalda.jpg`**

### `assets/js/custom/phoneCheck.js`
- Сообщение валидации `'Wrong number'` → **`'Número de teléfono no válido'`**

### `send.php`
- Убран костыль `$KEEP_LEADING_ZERO_NSNS = ['IT']` — итальянское исключение
  для ведущего нуля, Испании не нужно
- Справочники кодов стран оставлены как есть: это общая таблица на ~120 стран,
  для `ES` там уже всё верно (`+34`, 9 цифр), браузеру она не отдаётся

### Удалено из архива
- **Все `.log` файлы** — в них лежали реальные имена, телефоны и IP
  итальянских лидов (`crm.push.log` — 1.5 МБ, `m1.request.log` — 1.3 МБ).
  Заливать это на хостинг нельзя. Скрипты создадут файлы заново.
- `_preview.png` — скриншот итальянской версии
- Все `.DS_Store` (мусор macOS, 5 штук)

## ПРОВЕРЕНО

- В отдаваемых файлах не осталось ни итальянского текста, ни `it-IT`,
  ни `Italia`, ни итальянских имён файлов и якорей
- Лендинг отрисован в Chromium целиком (4365 px) — **ноль ошибок JS,
  ноль битых ссылок (404)**, весь текст на испанском
- Телефонный инпут инициализируется на **+34** с испанским флагом
- Форма отправляется: `POST send.php` → `303` → `ty/index.php?…&country=ES`
  → испанская страница благодарности
- `php -l` на `send.php` и `ty/index.php` — без ошибок
- `font-style: italic` в CSS шрифтов — это типографика, к Италии
  отношения не имеет, трогать не нужно

## ЧЕГО Я НЕ МЕНЯЛ

- Цены `186 €` → `29 €` — евро и в Испании евро, оставил
- Бейдж «Guaranteed SAFE Checkout / McAfee / Visa / Mastercard» — он
  английский, не итальянский. Но он про оплату картой, а лендинг про
  наложенный платёж — если смущает, можно убрать
- Фото (спина, шея, колени, руки, оператор колл-центра) — все нейтральные,
  без текста и без итальянских деталей
