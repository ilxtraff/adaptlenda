# ArtiZynt — лендинг под Испанию (ES)

Адаптация итальянского лендинга под Испанию. Итальянского языка и упоминаний
Италии в отдаваемых браузеру файлах не осталось.

---

## ⚠️ ЧТО НУЖНО СДЕЛАТЬ ПЕРЕД ЗАЛИВОМ

### 1. Видео — обязательно
Файла видео в исходном архиве не было, поэтому подставить его я не мог.
Лендинг ждёт файл в корне:

```
esARTIZYNT.mp4
```

Раньше было `itpotERECTAPLUS.mp4` — итальянская озвучка плюс логотип
итальянского телеканала **TG LA7** в кадре (видно на превью из архива).
Это самое заметное упоминание Италии на лендинге, и оно живёт внутри видео.
**Нужна испанская версия ролика** — с испанской озвучкой и без итальянских
телеканалов в кадре. Просто переименовать старый файл нельзя.

Ссылки на видео в двух местах `index.html` (строки ~60 и ~217).

### 2. Тайминг всплывающей кнопки под новое видео
В `index.html`:
```js
var start1 = 22 * 60 + 10;   // 22:10 — на этой секунде появляется кнопка
var duration1 = (24*60+47) - start1;  // до 24:47
```
Тайминг был подобран под итальянский ролик. Под испанский пересчитать.

### 3. Проверить ID оффера в партнёрке
Эти значения я не трогал — они из итальянской связки, и под Испанию у
партнёрки почти наверняка **другой оффер**:

| Где | Параметр | Текущее значение |
|---|---|---|
| `send.php` | `$PRODUCT_ID` | `16389` |
| `send.php` | `$REF` | `1028188` |
| `index.html` | `<input name="offer">` | `11695` |

Если не поменять — лиды из Испании уйдут в итальянский оффер или не зальются.

### 4. Проверить back-ссылку
`index.html`, `window.vitBack(...)` → `https://healthyworld.online/f9gMyD?...`
Если эта прокладка привязана к гео — поменять на испанскую.

## ПРОВЕРЕНО

- В отдаваемых файлах (кроме минифицированных библиотек) не осталось ни
  итальянского текста, ни `it-IT`, ни `Italia`
- В `js/utils.min.js` и `js/intlTelInput.min.js` метаданные Италии есть —
  это libphonenumber, справочник телефонных форматов всех стран.
  Пользователю не показывается, трогать нельзя, иначе сломается ввод телефона.
- Лендинг отрисован в Chromium: телефонный инпут сам встаёт на **+34** с
  испанским флагом, цены и таймер работают
- Страница «спасибо» отдаёт испанский при `country=ES`, при неизвестном гео
  и даже если передать `IT`; даты выводятся как «17 de septiembre de 2026»
- `php -l` на `send.php` и `ty/index.php` — без ошибок
- Все JS-файлы проходят проверку синтаксиса

## ИЗВЕСТНЫЙ БАГ (был и в итальянской версии, не трогал)

На странице «спасибо» JS пишет заголовок в элемент `#title`, но такого
элемента в разметке нет — блок `<div class="header">` пустой. Поэтому
крупный заголовок «¡Gracias por tu pedido!» не показывается. Если нужно —
добавить `<h3 id="title"></h3>` внутрь `<div class="header">` в `ty/index.php`.
